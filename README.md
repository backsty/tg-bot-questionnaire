# tg-bot-questionnaire

## Описание проекта
Этот проект представляет собой Telegram-бота, разработанного с использованием библиотеки Aiogram. Бот предназначен для проведения опросов и викторин, предоставляя пользователям интерактивный опыт.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL_репозитория>
   cd tg-bot-questionnaire
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` на основе `.env.example` и заполните его необходимыми переменными окружения, такими как токен бота и параметры подключения к базе данных.

## Запуск

Для запуска бота выполните следующую команду:
```
python -m app.bot
```

## Структура проекта

- `app/`: Основной пакет приложения.
  - `config.py`: Конфигурации бота.
  - `bot.py`: Инициализация бота.
  - `handlers/`: Обработчики команд и логики.
  - `keyboards/`: Клавиатуры для взаимодействия с пользователями.
  - `middlewares/`: Промежуточное ПО для обработки запросов.
  - `utils/`: Утилиты и состояния для управления логикой.
