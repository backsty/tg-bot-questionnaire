## 📋 Описание проекта

Telegram-бот "Questionnaire" предназначен для проведения тестирования по основам информатики для учеников 10 класса. Бот позволяет пользователям пройти тест из 10 вопросов, получить оценку по результатам и просмотреть свою статистику.

Разработан с использованием библиотеки Aiogram 3.20.0 и асинхронного подхода к обработке сообщений. Данные пользователей и результаты тестирования хранятся в базе данных PostgreSQL.

## 🔧 Требования

- Python 3.11+
- PostgreSQL 14+
- Токен бота Telegram (получается через @BotFather)

## ⚙️ Установка

1. **Клонирование репозитория**:
   ```bash
   git clone https://github.com/backsty/tg-bot-questionnaire.git
   cd tg-bot-questionnaire
   ```

2. **Создание виртуального окружения**:
   ```bash
   python -m venv venv
   
   # Активация на Windows
   venv\Scripts\activate
   
   # Активация на Linux/Mac
   source venv/bin/activate
   ```

3. **Установка зависимостей**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка базы данных**:
   - Запустите PostgreSQL локально или используйте Docker:
     ```bash
     docker-compose up -d
     ```
   - Выполните миграции для создания структуры базы данных:
     ```bash
     alembic upgrade head
     ```

5. **Настройка конфигурации**:
   - Создайте файл `.env` на основе `.env.example`:
     ```
     BOT_TOKEN=your_bot_token
     POSTGRES_USER=postgres
     POSTGRES_PASSWORD=your_password
     POSTGRES_DB=quiz_bot
     POSTGRES_HOST=localhost
     POSTGRES_PORT=5432
     DEBUG=True
     ```

## 💻 Функциональность

### Команды бота

- `/start` - начало взаимодействия с ботом, приветствие пользователя
- `/help` - инструкция по использованию бота
- `/quiz` - начало тестирования

### Прохождение теста

1. Пользователь нажимает кнопку "Начать тест" или вводит команду `/quiz`
2. Бот последовательно задает 10 вопросов по информатике
3. После каждого вопроса пользователь выбирает один из предложенных вариантов ответа
4. По окончании теста пользователь получает результат:
   - Количество правильных ответов
   - Оценку по 5-балльной шкале
   - Комментарий к результату

### Хранение данных

Информация о пользователях и результатах тестов хранится в базе данных PostgreSQL:

- Таблица `users`: данные пользователей Telegram
- Для хранения результатов используется поле JSON с историей прохождений тестов

## 🌐 Деплой

### Деплой на Render

1. Создайте аккаунт на [Render](https://render.com/)
2. Подключите репозиторий GitHub
3. Создайте новый сервис типа "Background Worker"
4. Настройте переменные окружения:
   - `BOT_TOKEN`
   - `POSTGRES_USER`
   - `POSTGRES_PASSWORD`
   - `POSTGRES_DB`
   - `POSTGRES_HOST`
   - `POSTGRES_PORT`
5. Укажите команду для запуска: `python main.py`

### Автоматический деплой через GitHub Actions

В репозитории настроен автоматический деплой при пуше в ветки main или master:

1. Настройте секреты в настройках репозитория GitHub:
   - `RENDER_SERVICE_ID` - ID сервиса на Render
   - `RENDER_API_KEY` - API ключ для доступа к Render

2. При каждом пуше в ветку main/master автоматически будет выполнен деплой

## 🗃️ Конфигурация базы данных

База данных PostgreSQL используется для хранения информации о пользователях и их результатах. Миграции базы данных управляются с помощью Alembic.

Команды управления миграциями:
```bash
# Создание новой миграции
alembic revision --autogenerate -m "описание миграции"

# Применение миграций
alembic upgrade head
```

## ❗ Возможные проблемы и их решение

1. **Ошибка подключения к базе данных**: 
   - Проверьте правильность учетных данных в `.env`
   - Убедитесь, что PostgreSQL запущен и доступен

2. **Ошибка валидации JSON при запуске**: 
   - Проверьте формат данных в `app/utils/quiz_data.py`

3. **Проблемы с форматированием клавиатур**:
   - При обновлении aiogram убедитесь, что используется актуальный API для создания клавиатур
   - Используйте `InlineKeyboardBuilder` и `ReplyKeyboardBuilder` для создания клавиатур
