# Директория миграций для Alembic

Эта директория содержит скрипты миграций базы данных.

Для создания новой миграции выполните:
```
alembic revision --autogenerate -m "описание миграции"
```

Для применения миграций выполните:
```
alembic upgrade head
```

Для отмены последней миграции:
```
alembic downgrade -1
```
